# AI黑客松 Skills

陪小学、初中和高中学生，把想法变成说得清、做得到、能验证的项目。

**一个入口，六个模块。** 学生直接说想做什么，AI 按需要调用，不用记步骤编号。

| 模块 | 能帮你做什么 |
| --- | --- |
| 文档整理 | 建立学生项目文件夹，自动归档；项目名称可以以后补 |
| 疾病调研 | 用类比和简单中文理解疾病、生活困难及已有办法，附资料来源 |
| 项目设计 | 讨论想法，形成五板块左文右图开题书；按项目组合产品外形、场景、交互、流程与架构 |
| ChatMaker | 接上需求，安装／调用原生 ChatMaker，先做基础原型再迭代 |
| 素材整理 | 检查开题书、概念图、制作照片、成品图／截图、演示视频 |
| 路演 | 主动调用平台制作能力，生成以图讲述的 PPT 或 HTML 演示及简短逐页讲解词；测试页可选 |

## 在 WorkBuddy 安装

新建一个能操作本地文件的任务，复制下面这段发给 WorkBuddy：

```text
请帮我从 GitHub 安装 AI黑客松 Skill：
https://github.com/Amasun93/ai-hackathon-skills
先读取仓库 INSTALL.md，按里面的方法直接从 GitHub 安装到 WorkBuddy 的技能目录。
不要下载 ZIP，不要只把链接记下来。已有同名技能先核对来源，不覆盖其他内容。
安装后检查 SKILL.md 和六个模块都能读到，告诉我怎样开始使用。
```

文件安装完成后，先检查 WorkBuddy 的“已安装”列表能否找到 `dawei-heikesong`；技能多时点“加载更多”或搜索。仍未出现时，等现有任务结束后关闭并重新打开 WorkBuddy，再检查。打开技能详情，点击“去试试”进入任务，选好保存课堂作品的外层文件夹，例如“我的黑客松项目”。然后说：

> 使用 AI黑客松。我叫小林，项目名还没想好，帮我建立项目文件夹。

支持 `/` 选择技能的版本，可在列表里选 `dawei-heikesong`。显示技术名称时，它就是 AI黑客松。安装目录、老师手动安装和更新办法见 **[安装说明](INSTALL.md)**。

## 上课可以这样说

- “我想了解白化病，请说得简单一点。”
- “我想帮助看不清小字的人，陪我把想法整理成项目方案。”
- “先按这些想法生成一页开题书，老师之后会帮我审核。”
- “按我的需求书用 ChatMaker 做一个基础原型。”
- “看看我的项目素材还缺什么。”
- “用现有素材做路演，PPT 或 HTML 都可以，并写每页简短的讲解词。”
- “继续我的项目。这次项目名称确定为‘大字阅读助手’，帮我改文件夹名。”
- “检查 AI黑客松 有没有更新，告诉我本地版本和新版改了什么。”
- “帮我更新 AI黑客松，保留我的项目文件和本地修改。”

项目开题书默认左侧五块：项目背景、现状分析、核心目标、核心功能、实验测试；右侧约一半用于一张或一组概念原理示意图。图应让读者看懂产品外形、使用场景、操作与反馈，关键部件要标注；可以综合使用漫画、流程图和架构图，不限定一种画法。图内不添加“概念示意·功能与形态待验证”等通用页脚小字，草案状态写在需求书正文。

路演默认约 7 页：封面、问题与现有办法、目标与方案、制作过程、作品演示、总结改进、结束；可合并，测试页可选，不设固定技术原理页，概念图可以整页呈现。PPT 与 HTML 演示都是正式形式，按用户要求或课堂条件选用；AI 主动寻找并调用当前平台合适的演示制作 Skill／工具，无需学生额外提醒。先定结构和每页重点，再安排解释问题的图片与短文字，最后完成排版；页面保留关键词、关键句和结论，详细解释放讲解词。多项目评审可采用每个 idea 一个标签页、顶部需求书、下面文字补充的组织方式，和分页路演按各自用途组织。

## 老师课前知道这几件事

- 本包提供教学方法和框架。联网调研、图片、PPT／HTML 演示制作、代码运行等依赖学生平台实际能力。没有演示制作能力时会先给内容与素材安排，不会假称已生成文件；只有 HTML 能力也可完成正式路演，明确要求 PPT 时则先说明格式缺口。
- [ChatMaker](https://github.com/Amasun93/ChatMaker) 按需独立安装，不会在安装本包时自动装整套硬件工具链。
- 学生文件保存在学生项目中。公开仓库只含 Skill 和说明，不接收学生照片、视频或私人资料。
- 疾病资料入口覆盖 31 个课堂主题，其中包含疾病组、常见病参照和功能困难主题，不能统称为 31 种罕见病；人数和治疗情况仍需调用时核验。
- 开题草案可由 AI 兜底起草，老师审核；课堂原型的模拟测试不代表医疗有效性验证。
