# 疾病调研：先让学生理解生活中的问题

默认直接以文字回复学生，用以下四部分组织。面向小学、初中、高中调整解释深浅；不知道年级时先用短句和生活例子，不先做一轮问卷。

## 先找到可靠信息

用 [疾病资料入口](disease-sources.md) 定位常见课堂主题，再按需要打开原文。它是截至所标日期的预检索入口，不是完整报告或最新医学数据库。没有命中的疾病照常检索。

优先专业机构、公开指南、学术综述、可信百科；患者组织可帮助理解生活困难，须区分组织经验、采访个案与普遍医学结论。分型影响结论时，先说明当前讨论的类型；“黄斑病变”“肌营养不良”等大类别不能直接套一个具体病型的人数和治疗。

人数、治疗与研究进展在调用时核对最新可用资料，标注资料年份、地区和统计口径。患病率、新发病例、出生发生率、登记人数各不相同；没有可靠的全球／中国总人数就明确说“暂未找到可靠总人数”，不要硬算一个数字。估算需说明依据和不确定性，不能当成全国登记结果。

## 四部分文字输出

1. **疾病基础介绍**：叫什么、全称、常见俗称（没有就说没有统一俗称）；怎样简单理解；生活里可能遇到什么困难。用一两个日常类比解释机制，再说明类比只帮助理解哪些部分，避免暗示人人表现相同。
2. **发病情况**：全球和中国大约有多少人或可查到什么统计。只采用有依据的数据；缺口明确保留。解释罕见不等于在某一个家庭或学校里不重要。
3. **生活痛点与治疗现状**：目前能否治愈，哪些是改善症状／减缓发展／探索研究；随后重点讲具体场景中的困难。可用简表“场景与困难 → 已有办法 → 帮到哪里 → 仍有哪些不便”。注意成本、携带、舒适度、操作条件和他人协助等实际影响，未核实的设计机会标为待讨论。
4. **拓展知识**：用“说人话”的类比解释成因或一个值得了解的原理；术语第一次出现就解释。不把基因问题描述成患者有过错，不夸大 AI 或学生作品的治疗作用。

关键医学、人数和研究结论就近给可点击来源，结尾可用很短的资料说明。不能只列一串链接却不说明支撑哪个事实。无法联网时说清哪些来自既有资料、哪些尚未核验，仍可解释已知的基础内容；不冒充刚刚检索过。

如果学生说看不懂，先换个更简单的例子，再问是否需要变成简报帮助理解。学生没提出理解困难时不默认生成简报、网页或 PPT。需要存档的文字放入 `01_需求书/调研资料/`，知识问答无需先创建文件。

研究用于课堂理解和生活辅助设计，不针对个人给诊断、用药或停药建议。提出项目方向时回到具体场景，不把同一疾病人群概括为同一种能力或需求。
