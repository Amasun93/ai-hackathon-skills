# 素材整理：检查是否到位，告诉学生怎样补

先读取当前项目目录里的实际文件，再按以下简表检查。文件存在和内容符合要求是两回事；能打开就查看，打不开或无法看视频内容就标“待确认”，不能凭文件名宣布全部合格。

| 基本素材 | 看什么 |
| --- | --- |
| 开题书／需求书 | 能找到当前版本并读懂目标、方案 |
| 独立概念图 | 独立文件可用，能看出方案；只在 PPT 里有时可用现有能力提取另存 |
| 制作过程照片 | 有学生实际制作过程的记录即可，不要求覆盖所有工序 |
| 成品照片／软件截图 | 实物至少正视图，侧视和俯视可补；纯软件用实际界面截图，不要求硬件三视图 |
| 演示视频 | 能展示作品如何使用或主要功能；未能播放则待确认 |

测试视频、测试数据、更多角度或细节照片是可选素材，按项目情况使用。不要追加固定照片数量、固定视频时长、复杂评分表。路演 PPT 是后续产物，不是本次检查的前提。

默认用短表或几句话回复“已有／缺少／待确认”，每个缺项给具体行动，例如“补一张你连接电路时的照片”“录一下从点击开始到看到结果的过程”。学生文件按原目录保存，必要的归档由文档整理衔接；不重复复制全套素材，不删原件。

基本素材齐了可以进入路演；有缺项时先说明缺在哪里。学生明确要先做路演草稿也可以继续，用“待补制作过程照片”等可识别占位，不把生成图当成真实制作或成品照片，不虚构视频。最终交付时仍如实说明未补项。
