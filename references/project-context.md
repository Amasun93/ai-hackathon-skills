# 找到同一个项目，接上已有工作

工作区是平台当前打开的外层文件夹；学生项目根目录在其中。先看当前目录和已有 `项目说明.md`，再查看与任务相关的真实文件。不要搜索学生整台电脑。

用户已经明确指定本次项目或保存目录时，就在该范围内找已有项目。没有找到说明文件可按本页直接创建；不为寻找格式样例而遍历上级目录或读取相邻学生的项目。只有学生明确指定需要参考的其他项目，才读取那一份相关材料。

- 已有学生项目时复用；有多个候选且无法辨认时，只问这次继续哪个。
- 新建正式项目缺姓名时询问姓名；项目名可空着。不要把匿名的知识问答也变成建档流程。
- “继续”不等于重新做全套。根据文件和说明恢复最近的目标、成果和未完成事项；说明与真实文件冲突时以检查结果为准，并修正过时链接。

根目录的 `项目说明.md` 是给 AI 和老师看的短说明，按实际需要维护，不需要学生填写。建议只保留：学生姓名、项目名称（未定可空）、一句话目标、当前阶段、最新文件的**相对链接**、重要假设／待确认项、下一步。没有的内容不虚构，不建立复杂状态机或逐条操作日志。

## 产物归位

| 内容 | 相对学生项目根目录的位置 |
| --- | --- |
| 开题书／需求书，包括一页开题 PPT | `01_需求书/` |
| 需要保存的疾病调研、来源或现状调研 | `01_需求书/调研资料/`（有文件才建） |
| 独立概念图、流程图 | `02_图纸/概念图/`、`02_图纸/流程图/` |
| 硬件程序、网页源代码、3D 源文件与导出 | `03_开发文档/` 对应子目录 |
| 制作过程、成品照片或软件界面截图 | `04_照片素材/` 对应子目录 |
| 演示、测试视频 | `05_演示视频和测试视频/` 对应子目录 |
| 路演 PPT、逐页讲解词 | `06_路演PPT/` |

每次产出文件就放入对应位置，不让学生再次手工分类。有同名文件先判断是已确认要修改的工作文件还是历史交付；需要保留的交付用两位版本号，如 `项目开题书_V01.pptx`。保留原件和可编辑源文件，不用占位空文件冒充成果。

工作区若没有文件写入权限，说明要切换到可操作文件的任务或打开项目文件夹；此时可以先讨论和整理内容，不能声称已建档。云端文件提供真实链接；只有成功导出后才登记为本地文件。
